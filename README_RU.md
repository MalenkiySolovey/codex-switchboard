## Обзор проекта

**Codex Switchboard** — это нативное приложение для Windows (WinUI 3 / .NET 10), объединяющее защищённое управление несколькими учётными записями, оперативный мониторинг лимитов запросов (rate limits) и безопасное хранение профильных ключей 2FA в едином удобном интерфейсе.

По умолчанию OpenAI Codex CLI сохраняет текущие учётные данные в единственном локальном файле: `%USERPROFILE%\.codex\auth.json`. Разработчикам, работающим с несколькими аккаунтами (личный, рабочий, клиентские, командные), приходится постоянно выполнять повторный вход через браузер, прерывая рабочий процесс. Кроме того, отслеживание оставшихся лимитов, таймеров сброса окон квот и кредитов сброса раньше требовало ручных запросов в консоли или сторонних скриптов.

Codex Switchboard решает эти задачи:
1. **Мгновенное атомарное переключение аккаунтов:** Безопасно подменяет учётные данные в `%USERPROFILE%\.codex\auth.json` за доли секунды с автоматическим сохранением обновлённых токенов (write-back), предварительной проверкой расшифровки и транзакционным откатом при сбоях.
2. **Телеметрия квот в реальном времени:** Отслеживает окна лимитов (например, 5-часовые и 7-дневные окна), проценты использования, оставшиеся кредиты сброса и статистику активности (Account Activity) для всех сохранённых аккаунтов в изолированных фоновых песочницах.
3. **Профильная безопасность 2FA / TOTP:** Локальная генерация одноразовых паролей с шифрованием DPAPI при хранении, автоматическим маскированием через 10 секунд и опциональным шлюзом подтверждения через Windows.

## Ключевые возможности

### Профильное хранение и генерация 2FA / TOTP
- **Привязка 2FA к профилю:** Надёжное сохранение секретных ключей TOTP (RFC 6238) индивидуально для каждого аккаунта.
- **Шифрование DPAPI при хранении:** Ключи шифруются через Windows DPAPI (`CurrentUser`) и изолированы в отдельных профильных файлах. Секреты исключены из экспорта профилей и системных журналов.
- **Маскированное отображение:** Коды скрыты по умолчанию (`2FA ••• ••• [Показать]`) и автоматически скрываются через 10 секунд или при потере фокуса окна.
- **Нативный шлюз подтверждения Windows:** Опциональная защита, требующая аутентификации через Windows Hello (биометрия/PIN) или пароль учётной записи Windows перед показом кода.
- **Проверка идентификатора пользователя (SID):** Доступ предоставляется только при совпадении SID подтверждённого пользователя с SID текущего процесса, исключая доступ из-под чужой учётной записи.
- **Безопасная работа с памятью:** Пароли Windows не сохраняются и не логируются, а временные буферы немедленно очищаются в памяти (`RtlSecureZeroMemory`).

### Мгновенное атомарное переключение
- **Переключение в один клик:** Быстрая смена активного профиля Codex прямо из списка карточек аккаунтов.
- **10-шаговая обратимая транзакция:** Строгая последовательность для 100% надёжности сохранности учётных записей:
  1. *Подтверждение и предварительные проверки.*
  2. *Быстрая проверка расшифровки (fail-fast)* целевого профиля до изменения файлов.
  3. *Обнаружение и корректная остановка процессов Codex*, чтобы избежать блокировки файлов.
  4. *Защита от состояний гонки (anti-race verification)*.
  5. *Синхронизация токенов (write-back)*: перехват токенов, обновлённых CLI во время сессии.
  6. *Создание зашифрованной резервной копии* текущего активного слота с меткой времени.
  7. *Атомарная замена файла* через временный файл.
  8. *Проверка конфигурации* (`cli_auth_credentials_store = "file"` в `config.toml`).
  9. *Обновление метаданных* в `profiles.json`.
  10. *Перезапуск процессов* для бесшовного продолжения работы.
- **Автоматический откат:** При возникновении любой ошибки во время переключения предыдущие активные данные мгновенно восстанавливаются из резервной копии.
- **Защита обновлённых сессий (Token Write-Back):** Всегда сохраняет обновлённые токены авторизации перед переключением, предотвращая сброс сессий.

### Мониторинг квот и лимитов в реальном времени
- **Динамические окна квот:** Поддержка любых окон лимитов, возвращаемых Codex, включая стандартные 5-часовые и 7-дневные окна, а также одиночные и настраиваемые периоды.
- **Цветовые пороги состояния:**
  - **Норма ($\ge 60\%$ остатка):** Зелёный индикатор достаточного запаса запросов.
  - **Предупреждение ($20\% - 59\%$ остатка):** Жёлтый индикатор приближения к лимиту.
  - **Критический ($< 20\%$ остатка):** Красный индикатор скорого исчерпания квоты.
- **Таймеры сброса высокой точности:** Наглядный обратный отсчёт времени до восстановления квоты (например, `2ч 15м` или `3д 18ч`).
- **Отображение кредитов сброса (Reset Credits):** Показывает доступные быстрые кредиты восстановления квоты, если они предоставлены сервером.
- **Мгновенный запуск из кэша:** Сохранённые снимки квот отображаются моментально при старте приложения и асинхронно обновляются в фоне.
- **Гибкое управление:** Отдельное обновление для каждого аккаунта и общая кнопка **«Обновить всё»**.

### Аналитика тарифов и подписок
- **Автоматическое определение тарифа:** Распознавание типа подписки (Plus, Team, Enterprise, Free) из данных профиля и ответов сервера.
- **Наглядные бейджи:** Отображение тарифа на карточке каждого аккаунта для удобного выбора нужного профиля.

### Телеметрия активности аккаунта (Account Activity)
- **Метрики использования и серии:** Отображение общего объёма использованных токенов за всё время, пика за день, длительности самого длинного ответа, текущей и максимальной серии дней активности (`account/usage/read`).
- **Распределение токенов по дням:** Интерактивное наглядное представление недавней суточной активности.
- **Определение возможностей рантайма:** Автоматическая диагностика поддерживаемых RPC-методов. При работе со старыми версиями рантайма Switchboard отображает информационный статус без нарушения мониторинга квот.

### Изолированные фоновые песочницы
- **Инвариант нулевой записи:** Фоновый опрос квот и сбор телеметрии **никогда не изменяют и не блокируют** основной рабочий файл `%USERPROFILE%\.codex\auth.json`.
- **Изоляция в песочнице:** Дочерние процессы `codex app-server --listen stdio://` запускаются в выделенных изолированных каталогах (`CODEX_HOME`), полностью независимых от рабочего окружения разработчика.
- **Контроль жизненного цикла:** Автоматическое завершение процессов и тайм-ауты исключают появление зависших фоновых процессов.

### Безопасная миграция данных
- **Лёгкий переход:** Автоматическое обнаружение установленного ранее `CodexSwitcher` в `%LOCALAPPDATA%\CodexSwitcher`.
- **Режим 100% только для чтения:** Файлы старого приложения не перемещаются, не модифицируются и не удаляются.
- **Точное копирование шифртекста:** Зашифрованные блобы DPAPI копируются побайтово, исключая лишние циклы расшифровки и повторного шифрования в памяти.
- **Защита целевой директории:** Миграция блокируется, если в новом расположении уже настроены профили, предотвращая случайную потерю данных.

### Настройки и системная диагностика
- **Переопределение пути к исполняемому файлу:** Возможность задать путь к пользовательскому `codex.exe` без изменения системной переменной `PATH` и перезапуска программы.
- **Инспектор возможностей:** Отображение пути к найденному файлу Codex, версии и статуса поддержки RPC-методов.

## Архитектура проекта

Codex Switchboard построен по модульной многослойной архитектуре с чётким разделением ответственности:

```
┌────────────────────────────────────────────────────────┐
│                   CodexSwitcher.App                    │
│      (WinUI 3 / XAML / MVVM / Windows App SDK 1.8)     │
│   • Представления и окна (Аккаунты, Настройки, Вход)   │
│   • Модели представлений (ViewModels) и состояние      │
│   • Диспетчер WinUI и адаптация тем оформления         │
└───────────────────────────┬────────────────────────────┘
                            │ зависит от
┌───────────────────────────▼────────────────────────────┐
│                  CodexSwitcher.Core                    │
│            (Бизнес-логика и абстракции)                │
│   • Координатор переключения (10-шаговая транзакция)   │
│   • Координатор мониторинга квот и опроса              │
│   • Диагностика и кэширование возможностей рантайма    │
│   • Модели предметной области, DTO и форматтеры        │
└───────────────────────────┬────────────────────────────┘
                            │ зависит от
┌───────────────────────────▼────────────────────────────┐
│                  CodexSwitcher.Infra                   │
│        (Интеграция с ОС и системными процессами)       │
│   • Хранилище учетных данных Windows DPAPI CurrentUser │
│   • JSON-RPC транспорт для headless Codex App-Server   │
│   • Изолированные песочницы профилей (CODEX_HOME)      │
│   • Управление процессами и блокировками               │
└────────────────────────────────────────────────────────┘
```

- **`CodexSwitcher.App`:** Слой пользовательского интерфейса на базе WinUI 3 с поддержкой Fluent Design Windows 11, эффекта Mica, адаптации к системной теме и `CommunityToolkit.Mvvm`.
- **`CodexSwitcher.Core`:** Чистая бизнес-логика и службы оркестрации, полностью изолированные от UI-зависимостей и покрытые модульными тестами.
- **`CodexSwitcher.Infra`:** Системный уровень: запуск процессов, криптография DPAPI, взаимодействие по JSON-RPC и файловые транзакции.

## Структура файлов и хранилища

Все настройки, учётные данные и кэш хранятся исключительно на локальном компьютере:

| Путь к хранилищу | Назначение | Переменная среды |
| :--- | :--- | :--- |
| `%LOCALAPPDATA%\CodexSwitchboard\` | Основная рабочая папка приложения (хранилище, профили, кэш, логи) | `CODEXSWITCHBOARD_HOME` |
| `%LOCALAPPDATA%\CodexSwitcher\` | Папка старого приложения (только для чтения при миграции) | `CODEXSWITCHER_HOME` |
| `%USERPROFILE%\.codex\` | Активная рабочая папка Codex CLI (`auth.json`, `config.toml`) | `CODEX_HOME` |

### Структура каталога данных
```
%LOCALAPPDATA%\CodexSwitchboard\
├── profiles.json          # Метаданные аккаунтов (email, псевдонимы, порядок отображения, тарифы)
├── settings.json          # Пользовательские настройки и путь к codex.exe
├── usage-cache.json       # Кэш снимков лимитов и активности для быстрого старта
├── audit.log              # Локальный журнал операций переключения (без токенов)
├── vault\                 # Зашифрованные данные аккаунтов DPAPI CurrentUser (<guid>.bin)
├── backups\               # Резервные копии активного профиля перед сменой
└── work\                  # Изолированные временные каталоги песочниц для опроса квот
```

## Безопасность и защита данных

- **Локальное DPAPI-хранилище:** Все учётные данные (`auth.json`) шифруются с помощью Windows Data Protection API (`DPAPI`) в области `DataProtectionScope.CurrentUser`. Ключи формируются на основе текущего сеанса Windows; мастер-пароли не используются и не передаются.
- **Нулевая телеметрия разработчикам:** В Codex Switchboard **полностью отсутствуют библиотеки телеметрии, аналитики, рекламы или сторонние облачные серверы**.
- **Сетевое взаимодействие:**
  - **Добавление аккаунтов через OAuth:** Встроенный браузер WebView2 подключается напрямую к официальным серверам авторизации OpenAI (`auth.openai.com`). Сессионные cookies сохраняются во временной изолированной папке.
  - **Опрос квот:** Официальный локальный файл `codex.exe` обращается к серверам OpenAI для проверки квот и телеметрии в соответствии с политикой конфиденциальности OpenAI.
  - **Отсутствие посредников:** Никакие промежуточные серверы не имеют доступа к вашим учётным записям.
- **Контроль единственного экземпляра:** Регистрация через Windows App SDK `AppInstance` (`CodexSwitchboard.SingleInstance`) безопасно перенаправляет аргументы запуска в основной процесс, исключая параллельную запись в файлы данных.
- **Принцип минимальных привилегий:** Приложение не требует прав администратора.

## Системные требования

- **Операционная система:** Windows 10 (версия 2004 / сборка 19041 или новее) или Windows 11 (x64).
- **Codex CLI:** Установленный OpenAI Codex, доступный в `PATH` (или указанный в Настройках).
- **Среда выполнения WebView2 Evergreen:** Требуется только для входа через OAuth (встроена в Windows 11; на чистых Windows 10/Server программа предложит прямую ссылку на официальный установщик Microsoft, при этом ручной импорт остаётся доступным).
- **.NET 10 SDK:** Требуется только для самостоятельной сборки из исходного кода.

## Сборка из исходного кода

### Предварительные требования
Установите [.NET 10 SDK (x64)](https://dotnet.microsoft.com/download/dotnet/10.0).

### 1. Клонирование и сборка
```powershell
# Клонирование репозитория
git clone https://github.com/MalenkiySolovey/codex-switchboard.git
cd codex-switchboard

# Восстановление зависимостей NuGet
dotnet restore CodexSwitcher.slnx

# Сборка проекта в конфигурации Release
dotnet build CodexSwitcher.slnx -c Release

# Запуск полного набора офлайн-тестов (458 тестов)
dotnet test CodexSwitcher.slnx -c Release --no-build
```

### 2. Создание локального установочного архива
Запустите скрипт сборки и упаковки:
```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-release.ps1 -Version "0.1.2"
```
Файлы сборки: `dist/CodexSwitchboard-0.1.2-win-x64.zip` и контрольная сумма `dist/SHA256SUMS.txt`.
